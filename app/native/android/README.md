# Native plugin — install into the generated Android project

The `android/` project is generated by `cap add android` and is **gitignored**
(build output). After generating it, wire in the `EposHardware` plugin:

## 1. Copy the plugin source
Copy `EposHardwarePlugin.kt` into the app's package source dir, e.g.:

```
android/app/src/main/java/uk/co/ricos/epos/EposHardwarePlugin.kt
```

(The `package` line in the file is `uk.co.ricos.epos` — keep it matching the
`appId` in `app/capacitor.config.json`.)

## 2. Register it in MainActivity
Capacitor auto-loads installed plugin *packages*, but an app-local plugin must be
registered. In `MainActivity.kt`:

```kotlin
package uk.co.ricos.epos

import android.os.Bundle
import com.getcapacitor.BridgeActivity

class MainActivity : BridgeActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        registerPlugin(EposHardwarePlugin::class.java)
        super.onCreate(savedInstanceState)
    }
}
```

## 3. Add the hardware SDKs (when wiring the TODOs)
In `android/app/build.gradle` dependencies:

```gradle
// Sunmi printer (woyou AIDL service) — confirm the current artifact/version,
// or vendor the AIDL from Sunmi's developer docs:
implementation 'com.sunmi:printerlibrary:1.0.18'   // example; verify

// Stripe Terminal + Tap to Pay on Android (Phase 3):
implementation 'com.stripe:stripeterminal-core:<version>'
implementation 'com.stripe:stripeterminal-taptopay:<version>'
```

Tap to Pay also needs: NFC + appropriate permissions, Google Play services,
location permission, and Stripe device eligibility — confirm the **exact T2
model** supports Tap to Pay on Android, otherwise pair an external Stripe reader
(WisePOS E).

## 4. Lock-down (kiosk) — optional but recommended for a till
Use Android **screen pinning** / a launcher restriction, or Sunmi's MDM, so the
device runs only this app. Set `android:screenOrientation` and disable the status
bar as desired in the manifest.
